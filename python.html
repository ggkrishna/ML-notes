1. The Scikit-learn API

Scikit-learn provides a uniform "Estimator" API. Every algorithm is an object that learns from data. The core methods are `.fit()` and `.predict()`.

Supervised Learning: `fit(X, y)`

Supervised models learn a mapping from features (X) to a target label (y). We train on labeled data and predict on new, unseen data.

# Supervised: X (features) and y (target)
from sklearn.model_selection import train_test_split
X_train, X_test, y_train, y_test = train_test_split(X, y)

# 'model' is any sklearn estimator
model.fit(X_train, y_train)
predictions = model.predict(X_test)

Unsupervised Learning: `fit(X)`

Unsupervised models find structure in data without labels. We `fit` to the data, then use `.transform()` or `.predict()` to get the results.

# Unsupervised: Only X (features)
from sklearn.preprocessing import StandardScaler
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

# 'model' is a clustering or transformer object
model.fit(X_scaled)
clusters = model.predict(X_scaled)

2. Core Parametric Models: Regression

These are the foundational models for predicting continuous values (like blood pressure) or binary outcomes (like disease risk).

Linear Regression Code

Used to predict a continuous value. The model learns a simple linear relationship from the features.

from sklearn.linear_model import LinearRegression

# Predict Blood Pressure (y) from Age (X)
model = LinearRegression()
model.fit(X_age, y_bp)

# Get the learned parameters
w1 = model.coef_      # Slope (w₁)
w0 = model.intercept_ # Intercept (w₀)

Logistic Regression Code

Used for binary classification. It outputs the *probability* that a sample belongs to a class.

from sklearn.linear_model import LogisticRegression

# Predict Diabetes (y) from Vitals (X)
model = LogisticRegression()
model.fit(X_vitals, y_diabetes)

# Get probability for a new patient
prob = model.predict_proba(X_new_patient)

3. Non-Parametric: K-Nearest Neighbors (KNN)

A simple and intuitive "instance-based" model. It classifies a new patient by finding the K most similar patients in the training data and taking a majority vote.

KNN Classifier Code

The `n_neighbors` parameter is the "K" you must choose. This model is sensitive to the scale of features, so scaling (e.g., `StandardScaler`) is almost always required.

from sklearn.neighbors import KNeighborsClassifier
from sklearn.preprocessing import StandardScaler

scaler = StandardScaler()
X_train_scaled = scaler.fit_transform(X_train)
X_new_scaled = scaler.transform(X_new_patient)

# Model to find 5 nearest neighbors
model = KNeighborsClassifier(n_neighbors=5)
model.fit(X_train_scaled, y_train)

# Classify a new patient
y_pred = model.predict(X_new_scaled)

4. Interpretable Decisions: Trees and Forests

Powerful models that create a series of "if-then" rules, making them highly interpretable. Random Forests improve performance by averaging many trees.

Decision Tree Code

We can control the tree's complexity by setting `max_depth` to prevent overfitting. The `criterion` can be 'gini' or 'entropy'.

from sklearn.tree import DecisionTreeClassifier

# Build a tree with Gini impurity, max depth 3
model = DecisionTreeClassifier(
    criterion='gini',
    max_depth=3
)
model.fit(X_symptoms, y_triage)

Random Forest Code

An "ensemble" model that builds many trees (`n_estimators`) on random subsets of data and features, then averages their votes.

from sklearn.ensemble import RandomForestClassifier

# Build a forest of 100 trees
model = RandomForestClassifier(
    n_estimators=100,
    max_features='sqrt', # Use random subset of features
    random_state=42
)
model.fit(X_train, y_train)

5. Introduction to Neural Networks

Scikit-learn implements a simple Multi-Layer Perceptron (MLP). For more complex tasks like image analysis, dedicated libraries are used.

MLPClassifier Code

This builds a "feedforward" neural network. We define the `hidden_layer_sizes` (e.g., 2 layers with 100 and 50 neurons).

from sklearn.neural_network import MLPClassifier

# A 2-layer network (100, 50 neurons)
model = MLPClassifier(
    hidden_layer_sizes=(100, 50),
    activation='relu',
    solver='adam',
    max_iter=500,
    random_state=42
)
model.fit(X_train_scaled, y_train)

Beyond Scikit-learn: Deep Learning

For specialized tasks like analyzing medical images (X-rays, MRIs) or clinical notes, the ecosystem shifts to more powerful libraries:

  • TensorFlow (with Keras): A comprehensive deep learning platform developed by Google.
  • PyTorch: A flexible framework popular in research, developed by Meta.

6. Beyond the Basics: Other Powerful Models

These models are workhorses for clustering (finding patient groups) and complex classification (finding non-linear patterns).

K-Means Clustering Code

An unsupervised model to find K distinct groups in data. We must specify `n_clusters` (K) in advance.

from sklearn.cluster import KMeans

# Find 3 patient clusters
model = KMeans(
    n_clusters=3,
    n_init=10, # Run 10 times, pick best result
    random_state=42
)
model.fit(X_scaled)

# Get cluster assignments and centroids
labels = model.labels_
centers = model.cluster_centers_

Support Vector Machine (SVM) Code

A powerful classifier that finds the "best" boundary between classes. The `kernel` trick lets it find complex, non-linear boundaries.

from sklearn.svm import SVC

# Use a non-linear RBF kernel
model = SVC(
    kernel='rbf',
    C=1.0,           # Regularization parameter
    probability=True # To use predict_proba
)
model.fit(X_train_scaled, y_train)
