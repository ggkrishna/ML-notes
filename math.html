1. A Formal Introduction to Learning

At its core, machine learning seeks to find a function \(f\) that maps inputs \(\mathbf{x}\) (patient features) to outputs \(y\) (diagnosis, risk score). This function is "learned" by minimizing a loss function over a dataset \(D\).

Supervised Learning (Task-Driven)

Given a labeled dataset \(D = \{(\mathbf{x}_i, y_i)\}_{i=1}^{N}\), the goal is to find a function \(f\) that minimizes the Empirical Risk (average loss):

$$R(f) = \frac{1}{N} \sum_{i=1}^{N} L(f(\mathbf{x}_i), y_i)$$

Where \(L\) is a loss function (e.g., Mean Squared Error for regression, Cross-Entropy for classification) that measures the penalty for an incorrect prediction.

Unsupervised Learning (Data-Driven)

Given an unlabeled dataset \(D = \{\mathbf{x}_i\}_{i=1}^{N}\), the goal is to find hidden structure. This is not optimized against a single loss function, but rather objectives like:

  • Clustering: Grouping data into \(k\) clusters to minimize within-cluster variance.
  • Dimensionality Reduction: Projecting data \(\mathbf{x}\) into a lower-dimensional space \(\mathbf{z}\) while preserving as much variance as possible.

2. Core Parametric Models: Regression

Regression models are parametric, meaning they define a fixed-form function \(f(\mathbf{x}, \mathbf{w})\) with parameters (or weights) \(\mathbf{w}\) that are learned from the data.

Linear Regression: The Model

Assumes a linear relationship. The prediction \(\hat{y}\) ("y-hat") is a weighted sum of input features \(\mathbf{x}\):

$$\hat{y} = w_0 + w_1x_1 + \dots + w_nx_n = \mathbf{w}^T\mathbf{x}$$

Weights \(\mathbf{w}\) are found by minimizing the Mean Squared Error (MSE), typically via Gradient Descent or the analytical Normal Equation.

$$L(\mathbf{w}) = \frac{1}{N} \sum_{i=1}^{N} (y_i - \mathbf{w}^T\mathbf{x}_i)^2$$

This chart visualizes the Ordinary Least Squares (OLS) best-fit line that minimizes the sum of squared residuals (vertical distances) for the data.

Logistic Regression: The Model

Adapts linear regression for binary (0/1) classification. It maps the linear output \(z = \mathbf{w}^T\mathbf{x}\) to a probability using the sigmoid function (\(\sigma\)):

$$P(y=1 | \mathbf{x}) = \hat{y} = \sigma(\mathbf{w}^T\mathbf{x}) = \frac{1}{1 + e^{-\mathbf{w}^T\mathbf{x}}}$$

It's trained by minimizing the Binary Cross-Entropy (Log Loss), as MSE is non-convex for this problem.

$$L(\mathbf{w}) = -\frac{1}{N} \sum_{i=1}^{N} [y_i \log(\hat{y}_i) + (1-y_i) \log(1-\hat{y}_i)]$$

The logistic S-curve maps any real-valued linear output to a probability between 0 and 1, allowing for a decision boundary (e.g., at P=0.5).

3. Non-Parametric: K-Nearest Neighbors (KNN)

KNN is an "instance-based" or "lazy" learning algorithm. It makes no assumptions about the underlying data distribution (non-parametric) and simply stores the entire training set.

The KNN Algorithm

To classify a new point \(\mathbf{x}_{\text{new}}\):

  1. Choose a value for \(K\) (e.g., K=5) and a distance metric.
  2. A common metric is Euclidean Distance:
    $$d(\mathbf{p}, \mathbf{q}) = \sqrt{ \sum_{i=1}^{n} (p_i - q_i)^2 }$$
  3. Find the \(K\) training samples (\(\mathbf{x}_1, \dots, \mathbf{x}_K\)) closest to \(\mathbf{x}_{\text{new}}\).
  4. Classification: Predict \(\hat{y}_{\text{new}}\) as the majority class of the K neighbors.
  5. Regression: Predict \(\hat{y}_{\text{new}}\) as the average value of the K neighbors.

Here, with K=5, the 5 nearest neighbors to the new point (orange) are found. The majority class (3 'Disease' vs. 2 'Healthy') determines its prediction.

4. Interpretable Decisions: Trees and Forests

Decision Trees are non-parametric models that learn a hierarchy of "if-then" rules. Random Forests improve their stability by averaging many trees.

Building a Decision Tree (CART)

Trees are built by recursively finding the "best" split (feature \(j\) and threshold \(t\)) that maximizes Information Gain. This is equivalent to minimizing the weighted impurity of the child nodes.

Common impurity measures for a node with class proportions \(p\):

  • Gini Impurity: \(G(p) = 1 - \sum_{k} p_k^2\)
  • Entropy: \(H(p) = - \sum_{k} p_k \log_2(p_k)\)
$$\text{Gain} = \text{Impurity}(\text{parent}) - [w_L \cdot \text{Impurity}(L) + w_R \cdot \text{Impurity}(R)]$$

Ensemble: Random Forest

A single tree has high variance. A Random Forest is an ensemble of \(B\) decorrelated trees. It uses two key techniques:

  1. Bagging (Bootstrap Aggregating): Each tree \(f_s\) is trained on a different bootstrap sample (a random sample of data *with replacement*).
  2. Feature Randomness: At each split, only a random subset of \(m\) features (where \(m < \text{total features}\)) is considered.

The final prediction is the majority vote (for classification) or average (for regression) of all B trees.

$$\hat{y}_{\text{rf}} = \text{majority\_vote}( \{ f_s(\mathbf{x}) \}_{s=1}^{B} )$$

5. Introduction to Neural Networks

Deep Learning models (Neural Networks) are powerful function approximators composed of layers of "neurons."

The Feedforward Neuron

A single neuron computes a weighted sum of its inputs, adds a bias \(b\), and passes the result through a non-linear activation function \(g(z)\) (like ReLU or sigmoid).

$$a = g(\mathbf{w}^T\mathbf{x} + b)$$

A full layer \(l\) is a vector of these operations, computing \(\mathbf{a}^{(l)}\) from the previous layer's activations \(\mathbf{a}^{(l-1)}\):

$$\mathbf{a}^{(l)} = g( \mathbf{W}^{(l)}\mathbf{a}^{(l-1)} + \mathbf{b}^{(l)} )$$

The entire network is trained using Backpropagation (an application of the chain rule) to compute the gradient of the loss function w.r.t. all weights \(\mathbf{W}\) and biases \(\mathbf{b}\).

Key Deep Learning Architectures

Different architectures are specialized for different data types:

  • Convolutional NN (CNN): Uses "convolution" filters to learn spatial hierarchies. Dominant in medical image analysis.
  • Recurrent NN (RNN/LSTM): Models sequential data by maintaining a hidden state. Used for time-series (EHR data, vitals).
  • Transformers: Use a "self-attention" mechanism to weigh the importance of different inputs. State-of-the-art for NLP (clinical notes).

6. Beyond the Basics: Other Powerful Models

The healthcare industry also leverages other sophisticated techniques to analyze complex data, from identifying patient groups to understanding clinical notes.

K-Means Clustering (Unsupervised)

An iterative algorithm to partition \(N\) data points into \(K\) clusters. It minimizes the Within-Cluster Sum of Squares (WCSS):

$$J = \sum_{k=1}^{K} \sum_{\mathbf{x}_i \in C_k} ||\mathbf{x}_i - \mathbf{\mu}_k||^2$$

Where \(\mathbf{\mu}_k\) is the centroid (mean) of cluster \(C_k\). It iterates between:

  1. Assign Step: Assign each point \(\mathbf{x}_i\) to its nearest centroid \(\mathbf{\mu}_k\).
  2. Update Step: Recalculate each centroid \(\mathbf{\mu}_k\) as the mean of all points assigned to it.

Support Vector Machines (SVM)

A classification model that finds the optimal hyperplane \(\mathbf{w}^T\mathbf{x} - b = 0\) that maximizes the margin (the distance) between the two classes.

This is a constrained optimization problem:

$$\min_{\mathbf{w}, b} \frac{1}{2} ||\mathbf{w}||^2 \quad \text{s.t.} \quad y_i(\mathbf{w}^T\mathbf{x}_i - b) \ge 1$$

The Kernel Trick (e.g., RBF kernel) allows SVMs to find non-linear boundaries by implicitly mapping data to a higher-dimensional space.

7. Ethical & Practical Considerations

The mathematics are objective, but the data they are trained on is not. Biased data (e.g., under-representing certain demographics) will lead to a model \(f\) that minimizes loss for the majority group, performing poorly and unfairly for minorities.

Pillars of Responsible AI in Healthcare

⚖️

Fairness & Bias

Ensuring the loss function \(L\) and dataset \(D\) do not lead to discriminatory predictions.

🔒

Privacy & Security

Protecting sensitive patient data \(\mathbf{x}_i\), often using techniques like differential privacy.

🔎

Transparency

Using interpretable models (like trees, LIME, SHAP) to understand *why* \(f(\mathbf{x})\) made its prediction.
