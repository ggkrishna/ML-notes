1. A Formal Introduction to Learning

At its core, machine learning seeks to find a function \(f\) that maps inputs \(\mathbf{x}\) (patient features) to outputs \(y\) (diagnoses, predictions).

Supervised Learning (Task-Driven)

Given a labeled dataset \(D = \{(\mathbf{x}_i, y_i)\}_{i=1}^{N}\), the goal is to find a function \(f\) minimizing expected loss:

$$R(f) = \frac{1}{N} \sum_{i=1}^{N} L(f(\mathbf{x}_i), y_i)$$

Where \(L\) is a loss function (e.g., Mean Squared Error, Cross-Entropy).

Unsupervised Learning (Data-Driven)

Given an unlabeled dataset \(D = \{\mathbf{x}_i\}_{i=1}^{N}\), the goal is to find hidden structure.

  • Clustering: Grouping data into \(k\) clusters to minimize within-cluster variance.
  • Dimensionality Reduction: Projecting \(\mathbf{x}\) to lower-dimensional space \(\mathbf{z}\).

2. Core Parametric Models: Regression

Regression models are parametric, meaning they define a fixed-form function \(f(\mathbf{x}, \mathbf{w})\) with parameters (weights) \(\mathbf{w}\).

Linear Regression: The Model

Assumes a linear relationship. Prediction \(\hat{y}\) is a weighted sum:

$$\hat{y} = w_0 + w_1x_1 + \dots + w_nx_n = \mathbf{w}^T\mathbf{x}$$

Weights \(\mathbf{w}\) found by minimizing MSE:

$$L(\mathbf{w}) = \frac{1}{N} \sum_{i=1}^{N} (y_i - \mathbf{w}^T\mathbf{x}_i)^2$$

Logistic Regression: The Model

For binary classification, maps output \(z = \mathbf{w}^T\mathbf{x}\) to probability:

$$P(y=1 | \mathbf{x}) = \hat{y} = \sigma(\mathbf{w}^T\mathbf{x}) = \frac{1}{1 + e^{-\mathbf{w}^T\mathbf{x}}}$$

Trained by minimizing Binary Cross-Entropy:

$$L(\mathbf{w}) = -\frac{1}{N} \sum_{i=1}^{N} [y_i \log(\hat{y}_i) + (1-y_i) \log(1-\hat{y}_i)]$$

The logistic S-curve maps any linear output to probability between 0 and 1.

3. Non-Parametric: K-Nearest Neighbors (KNN)

KNN is an "instance-based" or "lazy" learning algorithm. It stores the training set and makes predictions based on proximity.

The KNN Algorithm

Classify a new point \(\mathbf{x}_{\text{new}}\):

  1. Choose \(K\) and a distance metric.
  2. Common metric: Euclidean Distance:
    $$d(\mathbf{p}, \mathbf{q}) = \sqrt{ \sum_{i=1}^{n} (p_i - q_i)^2 }$$
  3. Find the \(K\) nearest training samples.
  4. Classification: Predict as majority class of neighbors.
  5. Regression: Predict as average value of neighbors.

With K=5, the majority class among 5 nearest neighbors determines prediction.

4. Interpretable Decisions: Trees and Forests

Decision Trees learn a hierarchy of "if-then" rules. Random Forests average many trees for stability.

Building a Decision Tree (CART)

Trees are built by recursively finding "best" feature splits.

Common impurity measures for node with class proportions \(p\):

  • Gini Impurity: \(G(p) = 1 - \sum_{k} p_k^2\)
  • Entropy: \(H(p) = - \sum_{k} p_k \log_2(p_k)\)
$$\text{Gain} = \text{Impurity}(\text{parent}) - [w_L \cdot \text{Impurity}(L) + w_R \cdot \text{Impurity}(R)]$$

Ensemble: Random Forest

A Random Forest is an ensemble of \(B\) decorrelated trees:

  1. Bagging: Each tree \(f_s\) trained on a bootstrap sample.
  2. Feature Randomness: At each split, only a random subset of \(m\) features is considered.

Final prediction: majority vote or average of all B trees.

$$\hat{y}_{\text{rf}} = \text{majority\_vote}( \{ f_s(\mathbf{x}) \}_{s=1}^{B} )$$

5. Introduction to Neural Networks

Deep Learning models are composed of layers of "neurons"—powerful function approximators.

The Feedforward Neuron

A neuron computes weighted sum, adds bias \(b\), passes through non-linearity \(g\):

$$a = g(\mathbf{w}^T\mathbf{x} + b)$$

A layer \(l\) stacks neurons:

$$\mathbf{a}^{(l)} = g( \mathbf{W}^{(l)}\mathbf{a}^{(l-1)} + \mathbf{b}^{(l)} )$$

Network trained using Backpropagation (chain rule on loss gradient).

Key Deep Learning Architectures

Specialized architectures:

  • CNN: Convolutional filters for spatial data.
  • RNN/LSTM: Sequential data, hidden state for time-series.
  • Transformers: Self-attention for NLP.

6. Beyond the Basics: Other Powerful Models

Healthcare leverages other techniques to analyze complex data, from clustering to support vector machines.

K-Means Clustering (Unsupervised)

Iteratively partition \(N\) points into \(K\) clusters, minimizing:

$$J = \sum_{k=1}^{K} \sum_{\mathbf{x}_i \in C_k} ||\mathbf{x}_i - \mathbf{\mu}_k||^2$$

Where \(\mathbf{\mu}_k\) is centroid of cluster \(C_k\).

  1. Assign: Assign each \(\mathbf{x}_i\) to nearest centroid.
  2. Update: Recalculate centroids as means.

Support Vector Machines (SVM)

Find optimal hyperplane \(\mathbf{w}^T\mathbf{x} - b = 0\) maximizing the margin:

Constrained optimization:

$$\min_{\mathbf{w}, b} \frac{1}{2} ||\mathbf{w}||^2 \quad \text{s.t.} \quad y_i(\mathbf{w}^T\mathbf{x}_i - b) \ge 1$$

The Kernel Trick allows nonlinear boundaries.
